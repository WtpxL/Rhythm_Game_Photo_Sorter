## 阶段 3：游戏识别

 目标：混合文件夹中自动判断每张图属于哪款游戏。

- 3.1 制定三款游戏分类特征（已完成：格式/分辨率 + 色彩启发式）
- 3.2 实现分类器并在现有 210 张图上评估（已完成：src/recognizers/game_classifier.py）
- 3.3 准确率不足时评估轻量图像分类模型（暂不需要：启发式已达标）
- 3.4 舞萌识别专项——「上屏」误判（已完成 2026-10-16）：
  国服舞萌竖屏图常同时拍到上屏（sub-monitor），其内容会干扰色彩启发式，导致误判为中二。
  解法：扩展舞萌专属 OCR 标签（新增 TOUCH触摸、BREAK绝赞、DX分数/DX评分、同步游玩/完全同步），
  分类仍以文字标签为主、色彩启发式为兜底。验证：识别流水线全量 238 张（舞萌 101/中二 72/Arcaea 65）
  100% 正确、无 unknown；evaluate_game_classifier 210/210；新舞萌样本 classify 21/21。
  （另验证：圆形主屏 HoughCircles 检测对舞萌、中二均可命中，不能作为区分特征，故未采用。）

设计依据（2026-10-15 用户补充）：同一游戏的结算页数据格式稳定（舞萌之间相似、
中二之间相似），颜色会因版本/拍摄/压缩而不同。因此游戏识别应以布局/结构特征为主，
色彩仅作辅助；歌名/难度字段提取也按各游戏稳定的布局定位。

完成标准：三款游戏分类准确率达到可接受水平（目标先定 95% 以上，按实测调整）。
（已达标：有把握的 209/209 张 100% 正确，1 张经微信压缩的中二图存疑待确认）
（后续：补充微信压缩/新版 UI 的舞萌、中二样本，校准分辨率无关的分类特征）
（2026-10-16：已按新样本修复「上屏」误判，见 3.4；分类口径统一为「文字标签优先、色彩兜底」，
classify 与识别流水线保持一致）

（收尾·全量评估 2026-10-17：scripts/evaluate_arcaea.py 跑全部 65 张——游戏分类 65/65、难度命中 64/65、歌名自动确认 48/65（73.8%）；其余 17 张进入人工确认/待处理（pending 8、deferred 9），无静默错误。失败类型：歌名候选待人工确认 8（OCR 部分识别，候选 0.5~0.7 未达自动阈值）、歌名未匹配·无有效文本 7（标题被立绘遮挡）、歌名未匹配·候选过低 2、难度缺失 1（IMG_0089 为课程/进度结算画面，无单曲难度）。）
